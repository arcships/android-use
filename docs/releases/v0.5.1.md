# Android Use v0.5.1

**Continuous capture. Fewer unnecessary reconnects.**

[English guide](https://github.com/JackCaow/android-use/blob/v0.5.1/docs/guide.md) · [中文指南](https://github.com/JackCaow/android-use/blob/v0.5.1/docs/guide.zh-CN.md) · [Preview implementation and validation](https://github.com/JackCaow/android-use/blob/v0.5.1/docs/preview-continuity.md)

## What's changed

- **Remove the routine 170-second reconnect.** Devices that explicitly document unlimited `screenrecord` support use it. Older builds keep one ADB pipe and one decoder across bounded recording segments.
- **Keep the picture during brief recovery.** A known-health encoder recovery or geometry refresh retains the displayed frame without a blocking overlay. Controls wait for fresh video and reliable geometry. Persistent failures, unknown lock state, authentication takeover and actual disconnection remain visible and clear the picture.
- **Stop treating display queries as a disconnected phone.** Optional display-metadata failures preserve healthy video, with coordinate actions disabled in both the UI and server until geometry recovers.
- **Improve capture lifecycle.** Real arrival-time frame sampling, bounded retry, ownership-checked process cleanup and a close-during-health guard. Compatible daemon revisions upgrade without older clients downgrading newer capture code.
- **Preserve existing MCP and Jev workflows.** All 24 standard MCP tools remain; Jev stays optional. No root, phone APK or new runtime dependency is required for ordinary preview.

## Validation and remaining limits

- **289 Python tests, 19 browser tests**, lint, clean-source builds and CI passed before release.
- **Android 16 physical native capture passed 190.187 seconds:** 1,198 distinct pictures, one encoder/ADB/decoder, no offline responses or health/metadata/stream failures. Maximum sampled/publisher gaps were **1.422 / 1.146 seconds**. Browser point inspections showed Live and advancing frame sequences.
- Physical forced two-second segments kept one ADB/decoder across 12 observed encoders; maximum sampled gap was 0.723 seconds. The raw compatibility harness result retains an error deliberately seeded while switching test modes; it is not presented as a clean whole-suite pass.
- **An earlier emulator native run still had a 4.147-second gap.** This patch removes routine reconnect disruption; it does not promise zero motion pauses on every device or host. Prior failures and truncated browser-network coverage remain documented.
- The temporary test page was uninstalled, the original foreground restored and the installed v0.5.0 preview service restored after acceptance. Publishing this release does not itself update your local installation.

## Download and install

`android-use-0.5.1-plugin.zip` contains the local plugin marketplace, Python source and lockfile, compiled screen, OCR helper, skill and bilingual docs. It is **not an Android APK**. `SHA256SUMS` contains its SHA-256 checksum.

Prepare **uv, ADB and ffmpeg**. The Codex plugin additionally needs the Codex CLI; optional built-in OCR requires macOS and Xcode Command Line Tools. First installation downloads Python dependencies.

```bash
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.5.1/android-use-0.5.1-plugin.zip
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.5.1/SHA256SUMS
# macOS; Linux: sha256sum -c SHA256SUMS
shasum -a 256 -c SHA256SUMS
unzip android-use-0.5.1-plugin.zip -d android-use-v0.5.1
cd android-use-v0.5.1
uv sync --frozen --python 3.13
codex plugin marketplace add .
codex plugin add android-use@android-use-release
```

Keep the extracted directory as the marketplace source. Existing users should update their original marketplace and preserve environment-file paths, saved Jev settings and other MCP servers; avoid enabling duplicate copies. Reload the MCP process after updating, then reopen preview so its authenticated daemon upgrades. The new recovery behavior needs the updated UI and server code.

### Other MCP clients

Android Use is **standard local stdio MCP**. Codex registration is optional. Merge this entry with your client's existing configuration:

```json
{
  "mcpServers": {
    "android_use": {
      "command": "uv",
      "args": ["run", "--frozen", "--directory", "/absolute/path/android-use-v0.5.1", "android-use-mcp"]
    }
  }
}
```

Cursor also uses `"type": "stdio"`; VS Code uses top-level `servers`. [Client examples](https://github.com/JackCaow/android-use/blob/v0.5.1/docs/guide.md#other-mcp-clients). The local preview URL is not a remote MCP endpoint.

Connect an ADB-authorized, unlocked device. Ask the Agent to check `aua_setup(action="status")`, start the service once only if absent, then verify `aua_ready` returns `ready=true`. Original tools need no API key. Enable optional Jev through the screen's settings gear using your own TypeSafe key; keep credentials out of chat and Git.
