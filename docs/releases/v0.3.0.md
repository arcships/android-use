# Android Use v0.3.0

**Give your agent an Android.** Standard local stdio MCP control, with a live screen you can follow.

[English guide](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.md) · [中文指南](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.zh-CN.md) · [Device acceptance](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/validation.md)

## What's new

- **Action → wait → observe in one call.** Actions accept `wait_for` conditions for a control becoming visible or disappearing. An unmet condition stops the batch without replaying the action.
- **Bounded auto-scroll search.** `aua_scroll_until` checks the current page, searches by selector, and stops on a match, its swipe/time limits, or repeated lack of progress. It does not click the result.
- **More native gestures.** `aua_long_press`, `aua_double_tap`, and `aua_drag` support explicit targets, postconditions, observations, and batch execution.
- **Interruptible waits and scrolling.** User pause bypasses operation locks; late observations are discarded. Nested waits/searches respect the batch's remaining budget. In-flight RPCs can overrun a time budget and cannot be recalled.
- **A directly installable plugin ZIP.** The archive includes its own `android-use-release` marketplace, compiled screen UI, locked Python dependencies specification, usage skill, and bilingual documentation.
- **English-first documentation.** Redesigned English/Chinese READMEs, a new project hero, complete user guides, client-specific setup, and device acceptance records.

The release includes **22 MCP tools**, Unicode/emoji text input and readback, independent H.264 live preview, direct PNG clipboard capture, and authentication handoff. No root, Appium, keyboard APK, or frontend build is required for normal use.

## Downloads

| Asset | Purpose |
| --- | --- |
| `android-use-0.3.0-plugin.zip` | Installable local plugin, Python source and lockfile, compiled UI, skill, and English/Chinese docs. This is not an Android APK. |
| `SHA256SUMS` | SHA-256 checksum for the plugin ZIP. |

Python itself, ADB, ffmpeg, and Codex are **not bundled**. Install [uv](https://docs.astral.sh/uv/getting-started/installation/), [Android Platform Tools / ADB](https://developer.android.com/tools/releases/platform-tools), [ffmpeg](https://ffmpeg.org/download.html), and the Codex client/CLI first. Use Python 3.11+; the commands below provision tested Python 3.13. First setup needs network access to install dependencies. Node.js, a JDK, and a full Android SDK are not needed for normal plugin use.

## Install the plugin ZIP

Download the two assets below. On macOS/Linux, run these commands in the download directory:

```bash
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.3.0/android-use-0.3.0-plugin.zip
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.3.0/SHA256SUMS

# macOS; on Linux you can use: sha256sum -c SHA256SUMS
shasum -a 256 -c SHA256SUMS
unzip android-use-0.3.0-plugin.zip -d android-use-v0.3.0
cd android-use-v0.3.0
uv sync --frozen --python 3.13
codex plugin marketplace add .
codex plugin add android-use@android-use-release
```

On Windows, download/extract the ZIP with your archive tool, open a terminal in the extracted directory, then run the uv/Codex commands. Reload the client's tools or open a new chat, enable Android Use, and confirm the `aua_*` tools are available. Keep this directory as the registered marketplace source. The [local marketplace mechanism](https://developers.openai.com/plugins/build/plugins) is documented by OpenAI; the ZIP extraction/CLI installation/tool-discovery path was also exercised for this release.

If you already use the source-checkout marketplace `android-use-local`, follow the [existing-installation update guide](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.md#updating) instead of enabling a duplicate server. Source installations keep their existing marketplace name; downloaded ZIPs use `android-use-release`.

### Connect the phone

Enable Developer options and USB debugging, connect a data-capable USB cable, approve the computer on the phone, and keep it awake/unlocked. Then, from the extracted directory:

```bash
adb devices -l
uv run android-use setup '{"action":"status"}'
# Only if the control service is absent:
uv run android-use setup '{"action":"start"}'
uv run android-use ready
```

Only **`ready=true`** proves readiness. With multiple devices, [select the target explicitly](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.md#select-a-device). Ask your agent to connect, verify READY, and call `aua_screen`. If the client cannot display MCP Apps, run `uv run android-use screen` and open its private local URL in a browser.

### Other MCP clients

The server is standard **local stdio MCP**. You can extract the same ZIP and use it without Codex plugin registration. After `uv sync --frozen --python 3.13`, configure clients using `mcpServers` as follows, replacing the absolute path:

```json
{
  "mcpServers": {
    "android_use": {
      "command": "uv",
      "args": ["run", "--frozen", "--directory", "/absolute/path/android-use-v0.3.0", "android-use-mcp"]
    }
  }
}
```

Cursor also uses `"type": "stdio"`. VS Code `.vscode/mcp.json` uses `servers` instead of `mcpServers`. See [complete client-specific configurations](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.md#other-mcp-clients). There is no remote HTTP/SSE MCP endpoint; the local video URL is not an MCP URL.

## Validation and scope

- **70 Python tests** and **6 browser tests**, plus CI checks and package builds.
- **11 real-device acceptance scenarios** passed on macOS / Python 3.13.7 with Android 16 / Xiaomi 15 Ultra through USB ADB. They cover delayed visible/gone conditions, native gesture events, scrolling, batch stopping, no replay on timeout, and pause/resume.
- The core device run took 64.08 seconds, excluding build/install/cleanup. The fixture was uninstalled and the original foreground app restored. This is not a cross-app performance benchmark.
- ZIP extraction, marketplace registration, plugin installation, and discovery of all 22 tools were tested; temporary release test registration was removed afterward.

Windows/Linux native-device operation, other manufacturers, high-latency wireless gestures, and all third-party MCP client versions have not completed end-to-end acceptance. Multi-touch, arbitrary paths, fine-grained text selection, and custom-editor input fallbacks are not provided. Passwords, PINs, codes, and biometrics remain with the user. Control/preview run locally; tool results are handled by the chosen MCP client/model.

## 安装方式

先安装 uv、ADB、ffmpeg 及 Codex 客户端 / CLI。发行包不含这些系统依赖；普通使用无需 Node.js、JDK 或完整 Android SDK。下载本 Release 的 ZIP 和 `SHA256SUMS`，macOS / Linux 在下载目录执行：

```bash
# macOS；Linux 也可使用 sha256sum -c SHA256SUMS。
shasum -a 256 -c SHA256SUMS
unzip android-use-0.3.0-plugin.zip -d android-use-v0.3.0
cd android-use-v0.3.0
uv sync --frozen --python 3.13
codex plugin marketplace add .
codex plugin add android-use@android-use-release
```

Windows 可使用解压工具，然后在解压目录执行 uv / Codex 命令。重新加载工具或新建聊天并启用 Android Use；保留解压目录作为市场来源。已从源码安装 `android-use-local` 的用户，按[更新指南](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.zh-CN.md#更新)更新原安装，避免同时启用两份服务。

手机开启 USB 调试、接受授权并解锁后，在解压目录执行：

```bash
adb devices -l
uv run android-use setup '{"action":"status"}'
# 仅当控制服务未启动时执行：
uv run android-use setup '{"action":"start"}'
uv run android-use ready
```

实际返回 `ready=true` 才代表可用。多台设备需明确选择，随后让 agent 打开实时屏幕。其他客户端可直接使用标准 stdio MCP，无需 Codex 插件，参见[中文完整指南](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/guide.zh-CN.md#其他-mcp-客户端)。

本次有 **70 项 Python 测试、6 项浏览器测试、11 项真机验收**。真机范围为 macOS + Android 16 / Xiaomi 15 Ultra；其他系统、厂商和客户端的验收范围详见[验证记录](https://github.com/JackCaow/android-use/blob/v0.3.0/docs/validation.md)。
