# Android Use v0.6.0

**Decide without a key. Find what the tree can't see.**

[English guide](https://github.com/JackCaow/android-use/blob/v0.6.0/docs/guide.md) · [中文指南](https://github.com/JackCaow/android-use/blob/v0.6.0/docs/guide.zh-CN.md) · [Host decider and Jev Box](https://github.com/JackCaow/android-use/blob/v0.6.0/docs/jev.md) · [Validation](https://github.com/JackCaow/android-use/blob/v0.6.0/docs/validation.md)

## What's changed

- **Keyless goal execution.** `aua_execute_goal` gains `decider=auto|jev|host`. Without an enabled TypeSafe key, it returns `status=decision_required` with compact state, option IDs and a one-time token. Your Agent answers with the new `aua_goal_decide` tool. Choices are bound to the screen they were made for: if the UI changed in between, the choice is discarded and a fresh decision is returned. Tokens are one-shot and in memory, and they expire after 5 idle minutes. The timeout counts device time only.
- **Opt-in Jev Box visual location.** New read-only `aua_locate`, plus a `visual` target on `aua_tap`, `aua_long_press` and `aua_double_tap`, for canvas, game, image and unlabeled targets. One request asks three questions: is the target present, how many match (none/one/several), and where is its box. When the first answer is uncertain on a downscaled screen, it asks once more on a native-resolution crop. A visual tap rechecks the pixels around the box before tapping once. Screenshots leave the device only after you turn on 「允许发送截图（视觉定位）」 in Jev settings (or set `ANDROID_USE_JEV_IMAGES=1`); this is separate from enabling Jev and off by default. Password, OTP and PIN screens, paused devices and secure windows are never captured.
- **Jev no longer retypes emoji.** The Android tree shows emoji as dots, so verified input looked unwritten. Verified writes are now remembered per field until the field changes, and history carries `verified_exact_text`.
- **Fewer phone reads, goal judgment.** Each step skips context checks that the snapshot read just made. On a Xiaomi device, per-step overhead fell from 0.44 s to 0.21 s (Jev goals) and from 0.34 s to 0.12 s (handoffs). Every Jev request also judges goal completion; without a completion selector, a confident ACHIEVED stops with `stop_reason=model_goal_achieved` and the result stays unverified.
- **Honest preview on devices without screenrecord.** HarmonyOS 4.2 lacks `screenrecord`. The preview now shows 「此手机不支持实时预览」 instead of retrying; screenshots, trees and actions keep working.
- **26 MCP tools** (new: `aua_goal_decide`, `aua_locate`). No new runtime dependency or phone APK.

## Validation and limits

- **362 Python tests, 24 browser tests**, Ruff and UI compilation passed. Each feature commit passed its own Python regression in an isolated worktree.
- **Host decider:** 6/6 real-device stdio acceptance on Huawei (HarmonyOS 4.2) and Xiaomi (HyperOS), with no key.
- **Jev:** 16/16 Xiaomi acceptance, including the emoji macro and goal judgment without a selector. The goal head adds about 120 input tokens per request.
- **Box:** 6/6 Xiaomi fixture acceptance. On Taobao's home page, 6 present targets were located inside their true bounds, including icons dimmed by a popup and a close glyph the tree only shows as a garbage character. Two absent targets were not found, and a visual tap closed an ad popup once. Each call took about 1.2 s and about 3,600 input tokens (≈$0.00015 at the published input price).
- TypeSafe marks images and Box as experimental, so the API may change. Presence judgments were tuned on a few apps; a located box is a model judgment, not verification. Pixel-only custom authentication cannot be detected, so pause first. Publishing does not update an installed or running plugin.

## Download and install

`android-use-0.6.0-plugin.zip` contains the local plugin marketplace, Python source and lockfile, compiled screen, OCR helper, skill and bilingual docs. It is **not an Android APK**. `SHA256SUMS` contains its SHA-256 checksum.

Prepare **uv, ADB and ffmpeg**. The Codex plugin additionally needs the Codex CLI; optional built-in OCR requires macOS and Xcode Command Line Tools. First installation downloads Python dependencies.

```bash
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.0/android-use-0.6.0-plugin.zip
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.0/SHA256SUMS
# macOS; Linux: sha256sum -c SHA256SUMS
shasum -a 256 -c SHA256SUMS
unzip android-use-0.6.0-plugin.zip -d android-use-v0.6.0
cd android-use-v0.6.0
uv sync --frozen --python 3.13
codex plugin marketplace add .
codex plugin add android-use@android-use-release
```

Keep the extracted directory as the marketplace source. Existing users should update their original marketplace and keep their environment-file paths, saved Jev settings and other MCP servers; avoid enabling duplicate copies. Reload the MCP process after updating, then reopen the preview so its authenticated daemon upgrades.

### Other MCP clients

Android Use is **standard local stdio MCP**. Codex registration is optional. Merge this entry with your client's existing configuration:

```json
{
  "mcpServers": {
    "android_use": {
      "command": "uv",
      "args": ["run", "--frozen", "--directory", "/absolute/path/android-use-v0.6.0", "android-use-mcp"]
    }
  }
}
```

Cursor also uses `"type": "stdio"`; VS Code uses top-level `servers`. [Client examples](https://github.com/JackCaow/android-use/blob/v0.6.0/docs/guide.md#other-mcp-clients). The local preview URL is not a remote MCP endpoint.

## 中文

v0.6.0 让没有 TypeSafe Key 的用户也能用 `aua_execute_goal`：返回 `decision_required`，由宿主 Agent 通过新工具 `aua_goal_decide` 逐步选择。选择绑定当时的界面，界面变了就作废重来；令牌一次性、5 分钟闲置过期，超时只计设备时间。

新增可选 Jev Box 视觉定位：只读的 `aua_locate`，以及点击、长按、双击的 `visual` 目标，用于 Canvas、游戏、图片和无标签图标。一次请求同时判断是否存在、匹配几个和框的位置；首轮在缩小的截图上不确定时，会按原分辨率局部放大再问一次。视觉点击先复核框周围像素，再只点一次。截图需在 Jev 设置中单独勾选「允许发送截图（视觉定位）」（或设置 `ANDROID_USE_JEV_IMAGES=1`），默认关闭；密码、验证码、PIN 页面、暂停状态和安全窗口一律不截图。

Jev 不再重复输入已核对的 emoji；每步少做重复的手机检查（小米上每步开销 0.44→0.21 秒）；每次请求附带目标完成判断。HarmonyOS 4.2 等没有 `screenrecord` 的手机会显示「此手机不支持实时预览」，不再反复重试。

362 项 Python、24 项浏览器测试通过。宿主决策在华为、小米真机各 6/6，Jev 在小米 16/16，Box 在小米测试 App 上 6/6；淘宝首页 6 个目标的框都落在真实控件内，每次约 1.2 秒、约 3,600 token。Box 属 TypeSafe 实验功能，定位结果是模型判断，不等于验收。下载、校验与安装方式同上。
