# Android Use v0.6.2

**Stable entry. Verified upgrades.**

[English guide](https://github.com/JackCaow/android-use/blob/v0.6.2/docs/guide.md) · [中文指南](https://github.com/JackCaow/android-use/blob/v0.6.2/docs/guide.zh-CN.md) · [Upgrade and recovery contract](https://github.com/JackCaow/android-use/blob/v0.6.2/docs/upgrading.md) · [Validation](https://github.com/JackCaow/android-use/blob/v0.6.2/docs/validation.md)

## What's changed

- **Stop launching from an expired cache directory.** The new installer creates independent runtime copies and a stable launcher under `~/.local/share/android-use/install`. The managed Codex plugin starts that launcher; removing old source/ZIP directories or obsolete Codex caches no longer changes its command.
- **Verify before switching.** Prepare frozen dependencies, then perform actual MCP initialize/tools-list checks on both the candidate runtime and the stable entry, including its expected version. Dependency/probe failure preserves the previous runtime. Registration failure restores its pointer/settings/config; if another editor changes unrelated config, keep that edit and retain the verified runtime for retry.
- **Find configuration conflicts.** Standalone `doctor` works even if MCP cannot start. `aua_doctor` includes the same configuration diagnostics. Detect duplicate Android Use plugins, manual-MCP/plugin conflicts, project overrides, versioned cache references and missing launch paths.
- **Migrate deliberately.** `--migrate-codex` handles recognized user-level Android Use overrides and other Android Use plugin registrations, preserving unrelated services and plugins. Unknown commands, unsupported config layouts and project overrides are refused. Private environment snapshots preserve existing launch settings; device/Jev state and screenshot consent remain unchanged.
- **Cover path and packaging edge cases.** Private environment files use relative runtime paths to avoid uv splitting paths containing spaces. Packaging no longer excludes all assets when a parent directory happens to be named `test-results`.
- All **26 existing MCP tools**, optional Jev, host decisions and MCP Apps remain available. No new Python runtime dependency or Android APK is required.

## Validation and limits

- **392 Python tests, 24 browser tests**, Ruff, UI compilation, clean-source wheel/sdist/plugin ZIP builds and PR CI passed before publication.
- Real stdio upgrade regression prepares old/new Android Use snapshots, keeps the command unchanged, deletes both sources and initializes a fresh host connection. Failure, configuration-preservation and concurrency cases are covered.
- Separate macOS historical acceptance: **v0.5.2 (24 tools) → v0.6.1 (26 tools)**, then delete both original sources, simulated old plugin caches and the original env file. The stable launcher still initializes correctly and preserves its private environment snapshot. No phone/model calls were made.
- Local pre-release migration checked v0.6.1 / 26 tools, zero config conflicts, healthy setup and `READY=true`; device/Jev/consent and unrelated config were preserved. This is distinct from loading a new version into an existing chat.
- Windows native upgrades have not been physically accepted. Keep the managed directory and Python/uv installations. A forced process/OS termination can leave an upgrade lock; confirm the installer stopped before removing it and retrying. Host tool reload and external configuration edits remain explicit recovery boundaries. Prior capture/OCR/vision limits are unchanged.

## Download and install

`android-use-0.6.2-plugin.zip` contains the installer, Python source/lockfile, compiled screen, skills and bilingual documentation. It is **not an Android APK**. Prepare **uv, ADB, ffmpeg**, plus the Codex CLI for Codex registration. First installation downloads Python dependencies.

```bash
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.2/android-use-0.6.2-plugin.zip
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.2/SHA256SUMS
shasum -a 256 -c SHA256SUMS  # Linux: sha256sum -c SHA256SUMS
unzip android-use-0.6.2-plugin.zip -d android-use-v0.6.2
cd android-use-v0.6.2
uv run --no-project --python 3.13 python scripts/install.py doctor
uv run --no-project --python 3.13 python scripts/install.py install --source . --codex
```

For a pre-existing `android-use-local`/`android-use-release` plugin or manual Codex MCP registration, review `doctor` and explicitly add **`--migrate-codex`** to the install command. Already-managed installations use the ordinary command again. Other servers/plugins are preserved. An existing direct entry's `--env-file` is copied privately; otherwise supply `--env-file /path/to/private.env` if needed. Later upgrades keep that snapshot unless you explicitly replace it.

Successful installation registers **`android-use@android-use-managed`**. Reconnect/reload the host tools, then verify the active version, device READY and live preview. The extracted directory can be removed after successful installation; keep the managed directory. Earlier runtime copies and private backups are retained; reinstall a known-good release with the same installer to switch back. [Full migration and recovery instructions](https://github.com/JackCaow/android-use/blob/v0.6.2/docs/upgrading.md).

### Other MCP clients

Android Use remains **standard local stdio MCP**. Omit `--codex`:

```bash
uv run --no-project --python 3.13 python scripts/install.py install --source .
```

Merge the returned stable `mcp_config` (`command` and `args`) into the client's `mcpServers` entry (VS Code uses `servers`). Use the same installer for future upgrades, then reconnect. No Codex CLI is required; do not point the client at a versioned Codex cache or a disposable extraction directory.
