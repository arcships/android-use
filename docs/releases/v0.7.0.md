# Android Use v0.7.0

**Your environment. Your installation choice.**

Android Use now offers optional native packages for macOS, Linux and Windows alongside the existing source plugin. Your Agent inspects the host, reuses a healthy installation and chooses the appropriate route. **A standalone runtime is not required.** All 26 MCP tools, keyless host decisions, optional Jev and live-screen integration remain available.

[English README](https://github.com/arcships/android-use/blob/v0.7.0/README.md) · [中文 README](https://github.com/arcships/android-use/blob/v0.7.0/README.zh-CN.md) · [Native installation and rollback](https://github.com/arcships/android-use/blob/v0.7.0/docs/standalone.md) · [Source upgrades](https://github.com/arcships/android-use/blob/v0.7.0/docs/upgrading.md)

## What's new

- **Optional standalone runtime:** includes CPython, locked Python libraries, ADB, minimal FFmpeg, the compiled UI and UiAutomator control JAR. No separate Python/uv, Node.js or JDK setup is needed on this route. Reuse an existing source environment when it already works.
- **Opt-in lightweight Dim plugins:** select the matching platform ZIP for first-use installation. Use Android Use in Dim Agent, describe a phone task, and follow the live phone view beside the chat. The README now shows an actual Dim Agent screenshot.
- **Verified updates and rollback:** check downloads and archive paths, probe bundled tools and a real MCP session, then promote one atomic pointer. Existing sessions keep running; the next MCP connection uses the new version. Failed updates retain the active version. Rollback rechecks the previous version and pauses automatic updates.
- **Optional macOS OCR:** omitted from the default native package. Install the separate precompiled component only when local text recognition is needed; no Swift compiler is needed by its users. Tree interaction, Agent screenshot inspection and Jev do not depend on this helper.
- **Optional interaction variation:** bounded timing and selector-point variation with reproducible seeds and existing execution guards. Disabled by default; it does not hide automation or guarantee avoidance of app detection.
- **Cross-platform fixes:** Windows preview resources use UTF-8, original license bytes survive CRLF-configured Git checkouts, and the Windows bootstrap hashes/extracts through .NET without depending on optional PowerShell functions.
- **Distribution notices:** the project's MIT copyright is attributed to **Archship**. Dependency licenses remain separate. Archives include CPython/package notices, certifi source form, corresponding FFmpeg source/build options and native inventories; known optional DBM/readline risks are blocked at build time. Thanks to [iPhone Use](https://github.com/zhongerxin/iPhone-use) for the inspiration.

## Pick a download

| Asset | Use it for |
| --- | --- |
| `android-use-0.7.0-plugin.zip` | Existing source/Codex installation, or any local stdio MCP client using Python/uv. Requires host ADB and ffmpeg for live video. |
| `android-use-0.7.0-PLATFORM-dim-plugin.zip` | Opt-in native bootstrap plugin for Dim Agent. Choose your platform below. |
| `android-use-runtime-PLATFORM.zip` | Manual/offline native installation, or a stable local MCP command for other clients. |
| `android-use-ocr-macos-arm64.zip`, `android-use-ocr-macos-x86_64.zip` | Optional macOS local OCR components. |
| `SHA256SUMS` | Checksums for every installation ZIP. |

`PLATFORM` is **`macos-arm64`** (Apple Silicon), **`macos-x86_64`** (Intel Mac), **`linux-x86_64`**, or **`windows-x86_64`**. Native Linux packages are built on Ubuntu 22.04. These are desktop packages, **not Android APKs**.

Download the selected ZIP and `SHA256SUMS` from this release. Compare its SHA256 with the matching line before extracting or running it. The repository may require GitHub authentication; use the browser while signed in or, for example:

```bash
gh release download v0.7.0 --repo arcships/android-use \
  --pattern android-use-runtime-macos-arm64.zip --pattern SHA256SUMS
# macOS, verifying only the ZIP downloaded above:
awk '$2=="android-use-runtime-macos-arm64.zip"' SHA256SUMS | shasum -a 256 -c -
# Linux: replace shasum -a 256 with sha256sum.
```

On Windows, `certutil -hashfile FILE.zip SHA256` can display the value to compare with `SHA256SUMS`.

## Install in Dim Agent

Ask your Agent:

> Install Android Use from https://github.com/arcships/android-use. Inspect my existing environment and choose source setup or the optional native package. Reuse healthy installations, preserve my settings and other MCP servers, verify the release checksum, register the returned local stdio command, then check READY and open the live phone view. I will handle USB authorization and unlocking. Leave Jev disabled until I configure it.

If choosing the lightweight native plugin, extract the matching `android-use-0.7.0-PLATFORM-dim-plugin.zip`, then install that directory through Dim's plugin management or:

```bash
dim plugin install /absolute/path/to/extracted-dim-plugin
```

First-use bootstrap needs network access and OS download/unzip utilities. A private release additionally needs GitHub CLI plus `ANDROID_USE_GITHUB_TOKEN` with asset read access; alternatively install the native archive offline first. Never put tokens in a chat or committed configuration. After native installation, updates use the bundled HTTP client rather than GitHub CLI.

### Manual native installation / other MCP clients

macOS example (replace the platform for Intel Mac or Linux):

```bash
unzip android-use-runtime-macos-arm64.zip -d android-use-runtime
./android-use-runtime/app/android-use-runtime install \
  --archive android-use-runtime-macos-arm64.zip \
  --sha256 REPLACE_WITH_THE_MATCHING_64_HEX_VALUE_FROM_SHA256SUMS
```

Windows PowerShell:

```powershell
Expand-Archive .\android-use-runtime-windows-x86_64.zip .\android-use-runtime
& .\android-use-runtime\app\android-use-runtime.exe install `
  --archive .\android-use-runtime-windows-x86_64.zip `
  --sha256 REPLACE_WITH_THE_MATCHING_64_HEX_VALUE_FROM_SHA256SUMS
```

Copy the returned **`mcp_config.command` and all `mcp_config.args`** into the client's local stdio MCP settings. Dim can use its MCP management; Claude Desktop/Cursor use `mcpServers`, while VS Code uses `servers`. Keep existing `env` settings and the intended state directory. Disable duplicate Android Use registrations. The native directory defaults to `~/.local/share/android-use/runtime`; keep it after deleting the downloaded ZIP/extraction.

Reconnect MCP, discover the 26 tools, then call `aua_setup(action="status")`, start only if needed, verify `aua_ready` and open `aua_screen`. The phone still needs debugging authorization, unlocking and a supported recording capability. Jev remains optional and can be configured in the screen's **Jev** settings.

### Source / Codex installation

Extract `android-use-0.7.0-plugin.zip`. Prepare uv and ADB; ffmpeg is needed for live video. From the extraction root:

```bash
uv run --no-project --python 3.13 python scripts/install.py doctor
uv run --no-project --python 3.13 python scripts/install.py install --source . --codex
```

For Dim or another MCP client, omit `--codex` and register the returned `mcp_config`. For a recognized older manual/Codex registration, review diagnostics and explicitly use `--migrate-codex`; already-managed installations can use the ordinary install command. Source installation remains supported and does not provision a native runtime automatically.

## Update, OCR and rollback

For native macOS/Linux installations:

```bash
/bin/sh "$HOME/.local/share/android-use/runtime/launcher.sh" update
/bin/sh "$HOME/.local/share/android-use/runtime/launcher.sh" install-ocr  # optional, macOS only
/bin/sh "$HOME/.local/share/android-use/runtime/launcher.sh" rollback
```

On Windows, use the returned native command and its `--root ROOT` arguments; replace the final `auto-serve` argument with the management command. Automatic checks occur at most once per 24 hours; `ANDROID_USE_AUTO_UPDATE=0` disables them. Rollback pauses checks until an explicit successful `update`. Original runtime versions and settings are retained. Moving from source to native is an explicit installation choice; the source launcher's private environment file is not silently imported.

A full desktop restart is not intrinsic to a runtime upgrade, but an existing MCP process is **not hot-replaced**. Reconnect/reload tools to start the selected version. Publishing this release does not update an already-running local installation.

## Validation and scope

The standalone implementation passed **481 Python regressions, 24 browser tests and Ruff**. Native acceptance passed **15 scenarios on each macOS architecture** and **13 each on Linux and Windows**: real stdio MCP/UI resources, install/upgrade/rollback, active sessions during promotion, bad-update preservation, private settings, bundled H.264 decoding, optional Mac OCR and packaged public/private bootstrap. The release pipeline repeats acceptance with the v0.7.0 binaries before publication.

These package checks perform **no phone actions or model calls**. Earlier device/Jev acceptance is separate. Bootstrap transport was stubbed in CI; live release-download smoke checks are reported separately. Packages are unsigned: new-user OS security prompts and OEM USB drivers are outside CI acceptance. Forced termination can leave a lock; verify the process has exited before cleaning it. SHA256 protects transfer integrity, not a compromised publisher. See the [validation record](https://github.com/arcships/android-use/blob/v0.7.0/docs/validation.md) and [license audit](https://github.com/arcships/android-use/blob/v0.7.0/docs/license-audit.md) for the exact boundaries.
