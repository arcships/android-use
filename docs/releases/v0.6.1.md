# Android Use v0.6.1

**Box stops guessing at text.**

[English guide](https://github.com/JackCaow/android-use/blob/v0.6.1/docs/guide.md) · [中文指南](https://github.com/JackCaow/android-use/blob/v0.6.1/docs/guide.zh-CN.md) · [Jev Box](https://github.com/JackCaow/android-use/blob/v0.6.1/docs/jev.md#visual-location-with-jev-box-opt-in-screenshots) · [Validation](https://github.com/JackCaow/android-use/blob/v0.6.1/docs/validation.md)

## What's changed

- **A Box over several text labels is no longer a target.** In a blind test on a real e-commerce app, Box confidently boxed a whole text row for small text such as prices and tags (3 of 8 targets missed, confidence 0.74–0.85). A located box is now checked against the accessibility tree. If it matches no single labeled or clickable node but covers two or more smaller labels (`reason=box_spans_text_nodes`), or covers one while its center falls between labels (`reason=tap_between_labels`), `aua_locate` returns `status=ambiguous` with no tap point and `tree_candidates` (label and rect) to select instead. A visual tap refuses with `ambiguous_target` and taps nothing.
- **Clearer scope.** Docs, the `aua_locate` description and the skill now say Box is for unlabeled icons, images and canvas, and that small text is unreliable: select text with tree selectors.
- No new tool, dependency or phone APK. `aua_locate` results can carry two new fields, `reason` and `tree_candidates`, only when the status is `ambiguous` because of this check.

## Validation and limits

- **367 Python tests** (5 new), 24 browser tests, Ruff and UI compilation passed.
- **Replay of the e-commerce blind run:** the 3 misses are flagged; none of the 10 correct targets are flagged.
- **Flutter app blind run** against an external host agent: Box 9/9 present and 2/2 absent targets at about 1.0 s and 3,600 input tokens per target; the host agent 27/27 and 6/6 over 3 runs. No guard flags, true or false.
- The check only sees what the tree exposes. Apps that merge a card's texts into one node (as this Flutter app does) or expose no tree are not covered. A located box is still a model judgment, not verification.

## Download and install

`android-use-0.6.1-plugin.zip` contains the local plugin marketplace, Python source and lockfile, compiled screen, OCR helper, skill and bilingual docs. It is **not an Android APK**. `SHA256SUMS` contains its SHA-256 checksum.

Prepare **uv, ADB and ffmpeg**. The Codex plugin additionally needs the Codex CLI; optional built-in OCR requires macOS and Xcode Command Line Tools. First installation downloads Python dependencies.

```bash
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.1/android-use-0.6.1-plugin.zip
curl -fLO https://github.com/JackCaow/android-use/releases/download/v0.6.1/SHA256SUMS
# macOS; Linux: sha256sum -c SHA256SUMS
shasum -a 256 -c SHA256SUMS
unzip android-use-0.6.1-plugin.zip -d android-use-v0.6.1
cd android-use-v0.6.1
uv sync --frozen --python 3.13
codex plugin marketplace add .
codex plugin add android-use@android-use-release
```

Keep the extracted directory as the marketplace source. Existing users should update their original marketplace and keep their environment-file paths, saved Jev settings and other MCP servers; avoid enabling duplicate copies. Reload the MCP process after updating, then reopen the preview so its authenticated daemon upgrades.

### Other MCP clients

Android Use is **standard local stdio MCP**. Codex registration is optional. Merge this entry with your client's existing configuration:

```json
{
  "mcpServers": {
    "android_use": {
      "command": "uv",
      "args": ["run", "--frozen", "--directory", "/absolute/path/android-use-v0.6.1", "android-use-mcp"]
    }
  }
}
```

Cursor also uses `"type": "stdio"`; VS Code uses top-level `servers`. [Client examples](https://github.com/JackCaow/android-use/blob/v0.6.1/docs/guide.md#other-mcp-clients). The local preview URL is not a remote MCP endpoint.

文档、工具描述和技能明确：Box 用于无标签图标、图片和 Canvas，文字请用控件树选择器。

367 项 Python、24 项浏览器测试通过。回放电商盲测：3 个漏判全部拦下，10 个正确目标无误判。Flutter 应用盲测中 Box 9/9、2/2，每个目标约 1.0 秒、约 3,600 token，与外部宿主 Agent 一致，守卫无触发。把卡片文字合并为一个节点的应用（如 Flutter）不在检查范围内。下载、校验与安装方式同上。
