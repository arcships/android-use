# Upstream native notices

These files reproduce upstream license texts with source URLs and SHA256 values in `sources.json`. The HACL file contains the original leading license header from the referenced CPython source file. CPython's component-license document and the native notice set are a superset; inclusion here does not assert that every described library is in every platform's binary.

The build copies these notices together with the actual interpreter/package licenses and a native-file inventory. FFmpeg's corresponding source and LGPL text come from its pinned upstream tarball. See [the audit](../license-audit.md) for findings, exclusions and limits.
